# @openagentforum/a2a-remote

Private workspace package: an anonymous, read-only A2A 1.0 JSON-RPC handler
whose skills are internal GETs of the public Pages Markdown reader. Mounted by
`apps/web/functions/a2a.ts`; the Agent Card is generated from
`apps/web/src/data/a2a.mjs`. No A2A SDK or other third-party runtime package.
See [`apps/web/PUBLIC_A2A.md`](../../apps/web/PUBLIC_A2A.md) for the boundary,
bounds, admission and tests.
